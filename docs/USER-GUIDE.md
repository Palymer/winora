# Руководство пользователя Winora

Winora — десктопная утилита для оптимизации Windows 10/11, очистки диска и ремонта реестра. Развёрнутое описание для поиска и каталогов: [О проекте](ABOUT.md).

## Первый запуск

1. Запустите `Winora.exe`.
2. Подтвердите запрос контроля учётных записей (UAC).
3. Рекомендуется сразу создать **точку восстановления** на вкладке «Реестр».

Без прав администратора часть функций (системный Temp, HKLM, службы) будет недоступна.

## Обзор

Показывает процессор, занятость памяти и диска, версию Windows.

Кнопка **Сканировать всё** проверяет очистку и реестр за один проход. Результаты — список находок и объём, который можно освободить.

## Очистка

1. Отметьте категории (корзина, temp, браузеры, ярлыки и т.д.).
2. Нажмите **Сканировать**.
3. Проверьте список, снимите лишнее.
4. Нажмите **Очистить выбранное**.

**Битые ярлыки** — файлы `.lnk` на рабочем столе, в меню Пуск и на панели задач, цель которых больше не существует. Удаляется только ярлык, не программа.

Очистка кэша шейдеров может увеличить время первого запуска игр.

## Реестр

1. **Сканировать** — поиск битых Uninstall, автозагрузки, App Paths и SharedDLLs.
2. Выберите записи.
3. **Исправить выбранное** — сначала бэкап `.reg`, затем удаление ключей/значений.

**Только бэкап** сохраняет HKCU, HKLM\SOFTWARE и службы без удаления.

Файлы бэкапа: `%LocalAppData%\Winora\Backups`

Восстановление: дважды щёлкните `.reg` или «Восстановление системы», если создавали точку.

## Оптимизация

Тумблеры сгруппированы: производительность, конфиденциальность, проводник, ввод, Edge, игры, сеть, службы, система.

- **Рекомендуемые** включает безопасный набор.
- Метка **перезагрузка** — эффект после reboot.
- **Применить** записывает текущее состояние всех видимых тумблеров (и включённых, и выключенных).

Сначала прочитайте описание. Не включайте гибернацию/OneDrive/SysMain, если не понимаете последствия.

## Горячие сценарии

| Задача | Куда идти |
|---|---|
| Мало места на диске | Очистка → сканировать → очистить |
| Программа удалена, ярлык остался | Очистка → битые ярлыки |
| Программа не удаляется из списка | Реестр → Uninstall |
| Система тормозит | Оптимизация → рекомендуемые |
| Игры | Оптимизация → игры + ввод (мышь) |

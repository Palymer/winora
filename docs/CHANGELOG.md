# История версий Winora

## 0.1.0-Alpha

Первый публичный альфа-релиз.

- Очистка: temp, корзина (`$Recycle.Bin` и Shell API), битые ярлыки, логи, дампы, кэш браузеров, Delivery Optimization, Prefetch, шейдеры GPU
- Ремонт реестра: Uninstall leftovers, автозагрузка, App Paths, SharedDLLs; бэкап `.reg` и точка восстановления
- Оптимизация: производительность, приватность, проводник, ввод, Edge, игры, сеть, службы
- Интерфейс: тёмная тема, боковая навигация (Обзор / Очистка / Реестр / Оптимизация)
- Portable `Winora.exe` (self-contained, win-x64)

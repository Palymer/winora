## Описание для GitHub / itch.io / каталогов (до 350 символов)

Winora — программа для оптимизации Windows 10 и Windows 11. Очищает временные файлы, корзину, кэш браузеров и обновлений, находит битые ярлыки и записи реестра, применяет твики производительности и приватности. Сначала предпросмотр, затем ваши действия. Есть бэкап реестра и точка восстановления.

## Полное описание

**Winora** (Windows optimizer) — утилита обслуживания операционной системы Microsoft Windows. Она помогает:

- ускорить работу компьютера за счёт отключения ненужных эффектов, задержек меню и фоновых служб телеметрии;
- освободить место на системном диске: `%TEMP%`, корзина, кэш Microsoft Edge, Google Chrome, Mozilla Firefox, кэш Windows Update и Delivery Optimization, дампы, эскизы, кэш DirectX/NVIDIA/AMD;
- починить реестр после удаления программ: недействительные ключи Uninstall, автозагрузка, App Paths, SharedDLLs;
- убрать битые ярлыки `.lnk` с рабочего стола, из меню «Пуск» и с панели задач;
- настроить конфиденциальность: Advertising ID, Cortana, Copilot, Recall, геолокация, журнал действий, советы Windows, Wi‑Fi Sense, телеметрия Office;
- подготовить игровой ПК: Game Bar / Game DVR, ускорение мыши, Multimedia SystemResponsiveness.

Winora не является антивирусом, не форматирует диск и не удаляет папки пользователя «Документы» и «Изображения». Это инструмент обслуживания, близкий по задачам к очистке диска Windows, редактору реестра и твикерам вроде Win11Debloat / Sophia Script, но с графическим интерфейсом на русском языке.

## Чем Winora не является

Не ISO-сборщик, не установщик программ через WinGet, не отключение Windows Defender «в один клик», не замена резервного копирования системы. Для этих задач используйте отдельные специализированные инструменты.

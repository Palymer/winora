# Безопасность Winora

Winora меняет систему. Используйте на своей машине и делайте точку восстановления.

## Как Winora снижает риск

- Сначала сканирование, потом ручной выбор
- Ремонт реестра не идёт без `.reg`-бэкапа
- Тумблеры обратимы (включение/выключение)
- Не отключаются Windows Defender и Windows Update
- Не удаляются установленные программы целиком (только мусор и битые ссылки)

## Чего лучше не трогать без нужды

| Опция | Риск |
|---|---|
| Prefetch | медленнее первый запуск приложений |
| Кэш шейдеров | дольше загрузка игр после очистки |
| SysMain | на HDD может стать хуже |
| Гибернация | пропадёт «сон» с быстрым возобновлением, удалится hiberfil.sys |
| OneDrive (политика) | перестанет синхронизироваться облако |
| SMBv1 | ломает доступ к очень старому NAS |

## Бэкапы

- `%LocalAppData%\Winora\Backups` — экспорт реестра
- Точка восстановления Windows — вкладка «Реестр»
- Журнал действий: `%LocalAppData%\Winora\Logs`

## Права

Нужен администратор. `dotnet run` сам показывает UAC; установка `requireAdministrator` в манифесте не используется, чтобы CLI мог стартовать процесс.
